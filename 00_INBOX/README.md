# 00_INBOX

Сюда пользователь загружает **все новые источники без предварительной сортировки**.

Можно сохранять исходные названия файлов. После анализа материал будет распределен по архиву, а его происхождение и новое местоположение будут зафиксированы в `INDEX/sources.md`.

Не использовать эту папку как постоянное тематическое хранилище.
