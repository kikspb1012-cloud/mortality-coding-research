# 07_AUTOMATION

Материалы по автоматизации кодирования и выбора причин смерти: отечественные системы, ACME, IRIS, DORIS и иные решения.

Отдельно фиксировать:
- автоматическое присвоение кода;
- работу по справочнику/словарю;
- выбор первоначальной причины смерти;
- реализованную версию правил;
- возможность ввода свободного клинического текста;
- прослеживаемость промежуточных решений.
