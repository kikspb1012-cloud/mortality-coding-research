# Реестр источников

| ID | Файл | Тип | Период / дата | Автор / орган | Тема | Текущее место | Статус разбора | Примечание |
|---|---|---|---|---|---|---|---|---|

## Правила

- каждой содержательно значимой единице присваивается ID;
- фиксируется исходное имя файла;
- при перемещении указывается новое место;
- `Статус разбора`: `не разобран`, `первично разобран`, `проверен`, `требует верификации`;
- библиографическая ссылка не заменяет анализа доказательной функции источника.
