# 08_DIGITAL_INFRASTRUCTURE

Материалы о современной цифровой инфраструктуре учета смертности:
- ФРМСС;
- ЕГР ЗАГС;
- федеральный центр кодирования смертности;
- региональные центры кодирования;
- электронные медицинские свидетельства;
- межведомственный обмен данными.

Задача раздела — проследить, как менялась архитектура передачи и обработки сведений, а не только форма документа.
