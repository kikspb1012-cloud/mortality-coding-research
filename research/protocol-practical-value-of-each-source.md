# Обязательный протокол практической оценки каждого источника

Решение пользователя, 2026-10-12. Применять ко ВСЕМ источникам историко-аналитического исследования, включая нормативные документы, диссертации, руководства, статьи и региональные материалы.

**Главный вопрос:** «Что именно практикующий врач или эксперт может непосредственно взять из этого источника для проверки правильности оформления медицинского свидетельства о смерти, кодирования, причинной последовательности, выбора/модификации ППС и исправления ошибок?»

Для каждого документа фиксировать:
1. Дословно/точно установленное практическое положение и страницу.
2. Проверяемый объект (поле, код, диагноз, причинная цепочка, ППС, часть II, реквизит).
3. Условие применения, исключение, приоритет, необходимые исходные сведения.
4. Однозначное проверочное действие врача/эксперта и результат (если в источнике есть). Не изобретать отсутствующие действия.
5. Уровень: технический / формальный / статистический индикатор / клиническое уточнение / классификационная экспертиза МКБ-10 / организационное исправление.
6. Что источник НЕ дает для самостоятельной комплексной экспертизы.
7. Ссылки на иные источники, без которых конкретное решение невозможно, и возможные противоречия по версиям.
8. Итог: часть какой практической проверочной системы действительно предоставлена.

Сводная научная задача: документально доказать, что имеются многочисленные полезные ЧАСТИ практических проверок, но насколько существует согласованная и доступная врачу единая система, требуется оценить на основе полного совокупного анализа (не заранее отрицать содержимое руководства Д. Ш. Вайсмана и существующих федеральных алгоритмов). Отличать текстовый фрагмент правила от полноценной сквозной процедуры проверки одного МСС.

Практический свод — логическое продолжение руководства Д. Ш. Вайсмана; не противопоставлять. Проблемные сочетания кодов (включая сахарный диабет) — для следующей научной статьи.
