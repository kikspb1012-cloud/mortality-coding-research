# 03_NORMATIVE_RUSSIA

Нормативные акты, письма, инструкции и методические документы Российской Федерации.

При индексации отдельно фиксируются:
- юридический/методический статус документа;
- дата;
- действие документа во времени;
- отмена или отсутствие явной отмены;
- связь с МКБ и международными обновлениями;
- адресат и предполагаемый механизм внедрения.
